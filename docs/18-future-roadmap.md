## 1. Feature Expansion Timeline

### Phase 1: Commercial Core & Agency Launch (Current Milestone)
- Multi-tenant Next.js application with PostgreSQL & Redis/BullMQ.
- Mailbox abstraction (SMTP/IMAP, Mailgun, SES, SendGrid).
- Spreadsheet wizard with auto-column discovery and auto-split name logic.
- Visual multi-step sequence builder with auto-reply cancellation.
- Unified inbox, deliverability advisor, public API lead ingestion, tiered billing.
- One-click Windows startup batch script package and Docker topology.

### Phase 2: AI Capabilities & Deep Integrations (Q3 2026)
- AI-powered reply intent classification (Positive Lead, Price Inquiry, Unsubscribe, Out of Office).
- Native CRM synchronization (HubSpot, Salesforce, Pipedrive).
- Advanced automated A/B sequence subject line and copy testing.
- OAuth 2.0 1-click connect for Google Workspace & Microsoft 365.

### Phase 3: Enterprise Scale & Distributed Warmup (Q4 2026+)
- Dedicated peer-to-peer automated mailbox warmup network.
- Dedicated IP pools and custom reverse DNS management for Enterprise tenants.
- Multi-region database read-replicas for ultra-low latency worldwide.
